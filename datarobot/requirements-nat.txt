# Path D: NeMo Agent Toolkit (dragent) workflow dependencies.
#
# This is separate from requirements.txt because it's a large, optional
# dependency set only needed to run agent/workflow.yaml (Path D) — it is
# not required for Path A (custom.py/DRUM), Path B (myagent.py), or
# Path C (server.py).
#
# Install with:
#   pip install --prefer-binary -r requirements-nat.txt
#
# --prefer-binary forces prebuilt wheels instead of building from source.
# This matters because litellm (a transitive dependency of
# datarobot-genai) ships a Rust extension that some corporate proxies
# can't build (crates.io access blocked), even though a prebuilt wheel is
# available on PyPI.
-r requirements.txt
# NOTE: nvidia-nat is pinned to exactly 1.7.0 because datarobot-genai[dragent]
# (all versions through 0.26.21, the latest as of this writing) requires
# nvidia-nat==1.7.0 as a hard dependency; a >= constraint here causes pip's
# resolver to fail with "ResolutionImpossible". Bump this only after
# confirming the datarobot-genai[dragent] version in use supports it.
nvidia-nat==1.7.0
nvidia-nat-langchain==1.7.0
datarobot-genai[langgraph,dragent]>=0.26.12
