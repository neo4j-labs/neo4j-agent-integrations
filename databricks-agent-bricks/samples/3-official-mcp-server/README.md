# Databricks Official MCP server (Neo4j via Databricks App)

This section covers how to deploy the **Official Neo4j MCP Server** using **Databricks Apps**.

By following this section, you can expose Neo4j based MCP Tools and interact with them using the Databricks Agent capabilities, enabling integration with LLM agents or other workflows.

Two different guides are present based on your needs:
- The **[Step-by-step](./STEP_BY_STEP.md)** guide covers in details all the aspects of the Databricks App implementation.
- The **[Straightforward](./STRAIGHTFORWARD.md)** guide lets you deploy the MCP server in minutes using automated scripts.
